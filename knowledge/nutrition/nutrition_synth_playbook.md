## What these synthesizers add

**Layne Norton (BioLayne):**
- Practical CICO application: flexible dieting, adherence over perfection
- Protein timing: total daily intake > distribution timing (≥160г/день приоритет)
- Diet breaks and refeeds: при дефиците >12 нед → 1–2 нед maintenance снижает адаптацию
- Fibre: ≥25г/день — satiety + gut health + glycaemic control

**Rhonda Patrick:**
- Микронутриенты: магний (сон/стресс), витамин D + K2 (иммунитет/кости), омега-3 (CRP)
- Time-restricted eating: окно 8–10ч; при нашем дефиците — не обязательно, но даёт adherence
- Sulforaphane (брокколи-ростки): anti-inflammatory → релевантно при CRP 5.1

**Attia (nutrition angle):**
- Protein first at every meal → mTOR / MPS — синхронизируется с нашим правилом
- Sat fat cap при elevated LDL → наш лимит 15г из directives.yaml

## Protocols IN THIS Health OS

**Применяем из Norton:**
- Белок 160г/день — жёстко; можно распределить 40/50/50/20г по приёмам
- Adherence > perfection: 1 день с превышением sat fat — не провал; средняя за неделю решает
- Дефицит −12% → при YELLOW Recovery Gate мягкий дефицит −10%; RED → maintenance

**Применяем из Patrick:**
- Омега-3 ≥2г EPA+DHA/день — из directives.yaml (CRP-директива)
- Витамин D + K2 — из supplements блока в daily log
- Окно питания: не жёсткое, но ≥ 1 час после подъёма первый приём

**НЕ применяем (Tier 1/2 не поддерживают):**
- Агрессивное TRE (4–6ч окно) при нашем объёме тренировок — риск дефицита белка
- "Кето для когнитивной энергии" — нет Tier 1 данных при умеренном дефиците у здоровых

- Norton: "грязный" bulk / любое питание в дефиците — нет, sat fat cap остаётся при любом паттерне
- Patrick: все добавки из её списка обязательны — нет, только по directives.yaml (omega3 + D)
