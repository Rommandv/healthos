# Health OS by Vlad Kuklev — Гайд по установке

> Персональная система здоровья на основе Medicine 3.0 (Peter Attia). AI выступает как команда из 5 ролей: врач-стратег, аналитик, планировщик, коуч и поведенческий терапевт.

---

## Что ты получишь

- **Коуч** — пишешь "съел омлет и творог" → он считает калории, белок, показывает остаток на день
- **Тренер** — спрашиваешь "что за тренировка сегодня?" → получаешь план с упражнениями
- **Стратег** — раз в неделю пересматривает план, корректирует калории и нагрузку
- **Аналитик** — загружаешь анализы → он оценивает по оптимальным значениям (не "лабораторной норме")
- **Поддержка** — сорвался, пропустил тренировку → zero judgment, разбор триггера, план возврата

## Уровень 1: Claude Code (5 минут)

### Что нужно
- [Claude Code](https://claude.com/claude-code) установлен
- Терминал (встроенный в Mac / VS Code / Cursor)

### Шаги

**1. Создай папку**
```bash
mkdir -p ~/health
```

**2. Скачай протокол**

Скопируй файл `health-system-setup.md` в папку и переименуй:
```bash
cp путь/к/health-system-setup.md ~/health/CLAUDE.md
```

Или просто создай файл `CLAUDE.md` в папке `~/health` и вставь туда содержимое протокола (файл `health-system-setup.md` из материалов когорты).

**3. Открой Claude Code в этой папке**
```bash
cd ~/health && claude
```

**4. Запусти настройку**

Напиши в Claude Code:
```
Настрой систему здоровья
```

Он спросит:
- Пол, возраст, рост, вес
- Цель (похудение / набор / поддержание / здоровье)
- Уровень активности
- Ограничения (травмы, аллергии)
- Тренировочный опыт
- Доступ к залу

На основе ответов автоматически:
- Рассчитает BMR, TDEE, калории и макросы
- Создаст тренировочную программу
- Заполнит все файлы системы
- Создаст slash-команды

**5. Пользуйся**

| Команда | Когда | Что делает |
|---------|-------|------------|
| `/health-daily` | Каждый день | Утренний бюджет, логирование еды и тренировок |
| `/health-review` | Раз в неделю | Пересмотр стратегии, корректировка плана |
| `/health-strategy` | Раз в месяц / после анализов | Обновление долгосрочных директив |
| `/health-labs` | Когда есть анализы | Загрузка результатов, оценка по оптимумам Attia |
| `/health-crisis` | Когда нужно | Срыв, тяга, пропуск — без осуждения |

### Примеры общения

```
> /health-daily съел 3 яйца, тост, авокадо

📊 Записал завтрак: ~450 ккал, 25г белка
Остаток на день: 750 ккал, 94г белка
🎯 Добавь белка в следующий приём — творог или курица
```

```
> /health-daily что за тренировка сегодня?

🏋️ Full Body A — акцент ноги
1. Goblet Squat — 3×8-12
2. Romanian Deadlift — 3×8-12
3. Push-ups — 3×8-12
4. Band Pull-apart — 3×12-15
5. Plank — 3×30-45 сек
```

```
> /health-crisis сорвалась на сладкое вечером

Бывает. Без драмы — давай разберёмся.
Что было перед этим? Проверим базовые:
- Белок за день набрала?
- Сон вчера как?
- Был ли длинный перерыв без еды?
[...]
```

## Уровень 2: Telegram-бот (30 минут)

> Чтобы не открывать терминал, а просто писать боту в Telegram — как Влад.

### Что нужно
- Всё из Уровня 1 (система уже настроена)
- [Anthropic API ключ](https://console.anthropic.com/) — ~$5-10/мес при активном использовании
- Python 3.10+
- Telegram-аккаунт

### Шаги

**1. Создай бота в Telegram**
- Открой [@BotFather](https://t.me/BotFather) в Telegram
- Напиши `/newbot`
- Придумай имя (например: "My Health Coach")
- Получишь токен вида `7123456789:AAH...` — сохрани его

**2. Получи Anthropic API ключ**
- Зайди на [console.anthropic.com](https://console.anthropic.com/)
- Создай ключ в разделе API Keys
- Сохрани его

**3. Попроси Claude Code собрать бота**

Открой Claude Code в папке `~/health` и напиши:
```
Собери мне Telegram-бота, который работает как Coach из этой системы.
Бот должен:
- Читать все файлы системы (directives, strategy, program, logs)
- Отвечать по роли Coach
- Логировать еду и тренировки в файлы
- Работать через Anthropic API (модель claude-sonnet-4-6)

Telegram token: [вставь свой токен]
Anthropic API key: положи в .env файл

Стек: Python, python-telegram-bot, anthropic SDK
```

Claude Code напишет бота, установит зависимости, и запустит.

**4. Запусти**
```bash
cd ~/health && python bot.py
```

Бот работает, пока терминал открыт. Для постоянной работы — разверни на сервере (VPS за ~$5/мес) или используй бесплатные тиры (Railway, Render).

## FAQ

**Сколько стоит?**
- Claude Code — бесплатно (нужна подписка Claude Pro $20/мес или API)
- Telegram-бот — Anthropic API ~$5-10/мес при ежедневном использовании
- Без Telegram (только Claude Code) — входит в подписку

**Нужно ли разбираться в программировании?**
- Уровень 1 — нет. Копируешь файл, открываешь терминал, пишешь по-русски
- Уровень 2 — нет, Claude Code сам напишет бота. Но нужно уметь запустить `python bot.py`

**Что если нет анализов?**
- Система работает и без них — считает калории, макросы, тренировки
- Nutrition constraints остаются пустыми, заполнятся когда сдашь кровь

**Можно в Cursor вместо терминала?**
- Да. Открой папку `~/health` в Cursor, включи Claude Code в терминале Cursor

**Что если я пропустил день/неделю?**
- Ничего. Напиши `/health-daily` когда вернёшься — система подхватит

## Что дальше

После установки:
1. Первая неделя — просто логируй еду и делай тренировки. Привыкни к системе
2. Вторая неделя — `/health-review` для корректировки
3. Когда будут анализы — `/health-labs` → `/health-strategy`
4. Если хочешь глубже — подключи трекеры (WHOOP, Oura) через MCP-серверы
