# Health OS — Consistency Audit (2026-06-20)

Read-only аудит дрейфа между `CLAUDE.md`, пятью `.claude/commands/*.md`, `knowledge/*` и фактическим поведением `bot.py` (роутинг интентов и чтение файлов). Сверка с архитектурой Влада Куклева (`knowledge/raw/vlad-kuklev.md`, `knowledge/raw/principles/vlad-principles.md`).

**Гейты аудита:** только чтение, `bot.py` не изменялся, новых ролей/фич нет. Каждый пункт помечен `fix-now` / `defer` / `leave`.

## Метод (что фактически делает рантайм)

- `bot.py` НЕ грузит весь набор файлов всегда — он выбирает подмножество по интенту: `context_files_for_intent()` ([bot.py:477](../bot.py)) + знание по теме `knowledge_files_for_intent()` ([bot.py:495](../bot.py)).
- Интенты: `meal / training / sleep_recovery / biomarkers_imaging / behaviorist / general` (`detect_intent` [bot.py:458](../bot.py)).
- Роль Coach в рантайме задаётся ВСТРОЕННОЙ строкой `RUNTIME_CONTEXT_INSTRUCTIONS` ([bot.py:38](../bot.py)), а НЕ файлом `CLAUDE.md`.
- Telegram-хендлеры: только `start`, `today`, `health_review` ([bot.py:3019](../bot.py)). Остальные slash-команды — Claude Code (стратегический слой), не Telegram.

## Findings

### F1 — `sources_lipids_longevity.md`: захардкоженные значения директив против реального `null` — **fix-now**

`knowledge/sources/sources_lipids_longevity.md` (строки ~22-24) утверждает:
- `nutrition.saturated_fat_limit_g: 15`
- `nutrition.omega3_minimum_g: 2`

Реальный `data/strategic/directives.yaml` — оба `null` (свежего ApoB нет → по no-data policy не выводятся). Прямой фактический десинк значений. Чинится в части C (доку-правка, без изменения поведения).

### F2 — `biomarkers.yaml`: глобальный `metadata.status: not_current_labs` помечает весь файл устаревшим, включая свежее ЭХОКГ 2026-03-03 — **fix-now (часть B)**

Верхний `metadata.status: not_current_labs` ([biomarkers.yaml:3](../data/strategic/biomarkers.yaml)) распространяется на весь файл, тогда как блок `cardiac_imaging_2026_03_03` свежее и не post-viral. CMO-гейт (`health-strategy.md`, шаг 2) читает только верхний metadata → считает устаревшим и мартовское ЭХО. Решается переводом свежести на уровень датасета (часть B). Не коммитится — на ревью человеку.

### F3 — `knowledge/index.md`: раздел «Runtime / Бот всегда читает» неточен против `bot.py` — **defer**

`index.md` (строки 7-16) заявляет, что бот ВСЕГДА читает `CLAUDE.md` + все data-файлы (directives, biomarkers, user_profile, strategy, program, meals, лог дня). Фактически:
- `CLAUDE.md` в рантайм НЕ грузится (вместо него `RUNTIME_CONTEXT_INSTRUCTIONS`).
- `biomarkers.yaml` — только при интенте `biomarkers_imaging` ([bot.py:485](../bot.py)).
- `meals.yaml` — только при `meal`; `program.yaml` — при `training/sleep_recovery/behaviorist`.
- `strategy.yaml` грузится почти везде, КРОМЕ `biomarkers_imaging`.
- Лог дня — только `meal/training/sleep_recovery/general` (`should_include_daily_log` [bot.py:491](../bot.py)).

Тематическая таблица папок в `index.md` (строки 28-39) при этом совпадает с `KNOWLEDGE_TOPIC_*` ([bot.py:95-112](../bot.py)) — она корректна. Десинк только в «всегда читает». Помечено `defer`: правка доку-только, но требует аккуратного переописания per-intent логики, а не замены значения — за рамки «однозначных» правок части C.

### F4 — `CLAUDE.md` шаблон директив дрейфует от реальной схемы `directives.yaml` — **defer**

Шаблон в `CLAUDE.md` (строки 181-214) старее реального файла:
- нет `epistemic_rules`, `pending_measurements`, `constraints.nutrition.fiber_minimum_g`, `protein_rule`, `constraints.recovery`, `max_vo2max_sessions_week`, `caffeine_delay_after_wake_min`;
- `active_modes.primary: body_composition` и `min_zone2_minutes_week: 90` против реальных `cognitive_performance` и `150`.

`CLAUDE.md` сам себя позиционирует как setup-шаблон, поэтому расхождение частично ожидаемо. Это канонический спек — правка чувствительна и нетривиальна. `defer` (отдельная задача синхронизации спека).

### F5 — `directives.yaml.metadata.valid_until` всегда `null`; CMO-workflow им не управляет — **leave**

Поле объявлено, но ни шаблон, ни `health-strategy.md` его не заполняют. Безвредно; опциональное улучшение CMO на будущее.

### F6 — В `bot.py` подключён только `/health-review`; остальные slash-команды — Claude-Code-only — **leave (by design)**

`CLAUDE.md` «Commands» (строки 55-61) подаёт все 5 команд единообразно, но в Telegram-рантайме реально есть только `health_review` ([bot.py:3022](../bot.py)). Это соответствует архитектуре Влада: стратегический слой (CMO/Analyst/Strategist-review) запускается вручную в Claude Code, тактический — в Telegram. Намеренное разделение, не дефект. (Можно при желании уточнить формулировку в `CLAUDE.md` — но это не ошибка.)

### F7 — Формулировки целей расходятся между файлами (не противоречат) — **leave**

`user_profile.goals.primary` («Hypertrophy with high cognitive energy…»), `goals.md` (Four Horsemen / centenarian) и `biomarkers.profile.goals` (`energy_9_10_daily`, `PBF_14_15_percent`, `VO2max_60`) описывают одно и то же разными словами. Не конфликт — оставить.
